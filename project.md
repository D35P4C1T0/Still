## Project

This repo will contain a lightweight TS project. The project is the best pomodoro timer website for my needs.
I will do study streams on twitch, so I need something to display on screen.
The ideal task for this project is to provide a obs compatible source that i can embeed in the stream so i dont have to screen share my browser; i chose web because i feel like we can achieve a good looking UI with minimal effort or use already existing ones that are already polished.

this project should mainly run in the terminal and print to the CLI just the useful stuff to get started.

#### References

These are the websites i take for inpsiration:
- https://pomofocus.io/
- https://studywithme.io/aesthetic-pomodoro-timer/

If those websites have a github repo you're more than welcome to clone it in a temp folder.
You should extract what's great about each website and what everyone adds or changes compared to the standard pomodoro timer concept.

MY project will be the best mashup of all the links above; I'll be focusing heavily on the UI design, it should be not distracting, calming, chill, a good vibe, reassuring. You can add tasteful animations. I like the vibe of lava lamps. Prefer dark themes, yet also add a white one.

### Music

It will be also possible to add a folder for music background; this project should offer a minimal music player UI that shows the title of the song played and playback controls (no progress bar).
You should offer TUI playback controls (keybindings when inside the terminal). You can pick HJKL vim like for the playback.
The most important thing is that song should have a configurable cross fade. Also fine volume control is very needed in the TUI, don't show it in the webui.
